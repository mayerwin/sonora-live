# Built-in piano samples

**Splendid Grand Piano**: a Steinway grand sampled by Akai and released into the **public domain**, in the
version remastered and mapped by the [SFZ Instruments](https://sfzinstruments.github.io/pianos/splendid_grand_piano/)
project (4 velocity layers). The Opus (`ogg/`) and AAC (`m4a/`) encodings come from
[smpldsnds/sfzinstruments-splendid-grand-piano](https://github.com/smpldsnds/sfzinstruments-splendid-grand-piano).

File names: `<layer>-<note>`, layers `pp`, `mp`, `mf`, `ff`; notes as in the sample set, where middle C is `c3`
(`s` = sharp, `m1` = octave -1). The engine that plays them is `src/midi/piano.ts`.
